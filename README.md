# Storm Risks for State Hazard Mitigation Planners

This project uses NOAA's storm events data in Big Query to identify which hazard types account for the largest number of deaths, injury, and damage to property and crops in each state and how those losses have changed over time. The findings aim to help show where sever weather have causes the most harm so that emergency planners can better understand the local risks.
